# 作业 1（Assignment 1）

## Experience a Coding Agent: Build a Web UI for Claude Code

## 体验编程智能体：为 Claude Code 构建网页用户界面

### Requirements

Start as an agent user. Use Claude Code to build a web UI for Claude Code itself—a browser front end that drives a real agent session. The application is deliberately large enough that the agent must inspect files, run tools, and recover from errors.

Then take the agent apart. Instrument the trajectory, classify what actually filled the context, and analyze three substantive failures.

We are not grading how impressive the interface looks. We are grading what you learned about how the agent executed.

### 作业要求

以智能体用户的身份开始。使用 Claude Code 为 Claude Code 本身构建一个网页用户界面，这是一个驱动真实智能体会话的浏览器前端应用。该应用程序的规模特意设计得足够大，要求智能体必须检查文件、运行工具并从错误中恢复。

然后拆解该智能体。记录其执行轨迹，对实际填充上下文的内容进行分类，并分析三类实质性故障。

我们不对界面的视觉美观程度评分，而是评估你对智能体执行过程的理解程度。
